# Smart Campus Energy & EV Fleet

## Run locally

Use Python 3.9–3.12. Place the coursework file `ev_campus_dataset.csv` in
the project directory and run these commands from that directory.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python pipeline.py
python a1_telemetry.py
python alert_fees.py
python demo_data.py
python -m streamlit run app.py
```

On Windows, activate the environment with `.venv\Scripts\Activate.ps1`.
The pipeline writes `output/cleaned_energy_sales_data.csv` and prints descriptive statistics.
Run `python charts.py` to regenerate the five figures under `output/figures`.

## Data and billing

- `ev_campus_dataset.csv` is the main source. The original
  `cleaned_energy_sales_data.csv` is the supplied billing reference.
- `sales_data.csv` contains separate retail transactions without an EV session join key.
- `demo_session_timestamps.csv` assigns demonstration dates to supplied session IDs while
  preserving their start hour. `demo_campus_telemetry.csv` contains demonstration hourly
  ambient temperature, grid load and solar power. Both are generated by
  `python demo_data.py`. These values are synthetic, including in downloaded records.
- B1 uses the tariff reproduced from the supplied clean table. The A2 15% high-risk
  surcharge is calculated separately. Alert deltas compare the preceding equal-length
  date window with the same filters.
